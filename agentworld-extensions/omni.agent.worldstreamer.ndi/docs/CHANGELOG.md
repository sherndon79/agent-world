# Changelog

All notable changes to the Agent WorldStreamer (NDI) Extension will be documented in this file.

## [0.1.0] - 2025-09-30

### Added
- Initial NDI extension based on WorldStreamer SRT
- GStreamer NDI plugin integration
- Network-discoverable NDI streaming
- Simplified pipeline (no encoding needed - NDI handles internally)
- Configurable NDI source name and groups
- Low-latency viewport capture for NDI transmission
